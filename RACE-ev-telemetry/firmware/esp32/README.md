# ESP32 firmware

Place the final, tested ESP32 GPS + microSD logger sketch in this folder (for example, `esp32_gps_sd_logger.ino`). The Nano firmware was available in the supplied source; a final integrated ESP32 logger source was not included in that source file, so this package does not invent or label a placeholder as production firmware. Include the libraries, board settings, pinout, and a sample CSV row when adding the tested sketch.
